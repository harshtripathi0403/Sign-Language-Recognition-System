# Sign Language Recognition System

## Overview
A real-time American Sign Language Recognition System developed using Python, OpenCV, and Machine Learning. The system detects hand gestures and converts them into text to improve communication accessibility.

## Features
- Real-time gesture recognition
- Hand landmark detection
- Machine learning based classification
- User-friendly interface
- Text generation from sign gestures

## Technologies Used
- Python
- OpenCV
- NumPy
- Scikit-Learn
- Tkinter

## Project Structure
- frontend_app.py
- realtime_predict.py
- asl_detection.py
- dataset_keypoint_generation.py

## Installation
pip install -r requirements.txt

## Run
python frontend_app.py
